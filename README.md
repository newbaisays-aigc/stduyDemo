# V2.2 Open Source Edition

这是一个面向语文教研与题库整理场景的本地化学习图谱工具，适合用于：
- 题目结构化整理
- 题库编辑与维护
- 试卷结构拆分与校验
- 古文、古诗词与阅读知识整理
- 二次开发与公开演示

## 核心能力
- 题库浏览：按年份、题型、知识点查看内容
- 结构化编辑：题干、选项、答案、解析分栏维护
- 试卷结构：支持一级标题、二级标题、材料、题目等层级管理
- 题目管理：支持新增、编辑、删除、导入、导出
- 本地保存：所有结构数据可写回本地文件
- 公开演示：保留交互流程，方便 GitHub 用户直接运行

- ## 公开版边界
公开版只保留：
- 页面框架
- 结构化逻辑
- 演示题目
- 古文与古诗词相关知识整理

公开版不包含：
- 已校对的真实真题正文
- 手工整理的完整答案库
- 私有图片与上传资源
- 受版权限制的教材原文

## 技术结构
- 前端：单页 HTML + 原生 JavaScript
- 后端：Python 本地服务
- 存储方式：JS/JSON 式本地文件存储
- 运行方式：浏览器直接访问本地服务页面

## 目录说明
- `people-knowledge-graph-V2.2-open.html`：公开版主页面
- `server.py`：本地服务入口
- `supplemental-bank.js`：公开版古文/古诗词知识库
- `clean-knowledge-bank.js`：公开版清洗知识库
- `exam-*.js`：公开版结构辅助文件


## 运行方式
- 先启动 `server.py`
- 浏览器打开 `http://127.0.0.1:8001/people-knowledge-graph-V2.2-open.html`
- 也可以把这个页面地址给任何一个AI，跟它说帮忙启动这个页面

## 适用人群
- 语文老师
- 题库整理者
- 教研协作者
- 想学习题库结构化实现的开发者
